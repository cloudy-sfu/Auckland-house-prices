# Database

I use Neon[^1] serverless database in this program, so all the configs are tested on Neon. However, any PostgreSQL database works in this program.

[^1]: Visit https://neon.com/ to learn more.

Create a PostgreSQL 17 database.

Refer to `database_schema.sql` to mock the database schema. This file is generated by `pg_dump` [^2].

[^2]: Can be downloaded from https://www.enterprisedb.com/download-postgresql-binaries

Include the following variables into environment variables, which will be used by all the data collection jobs, modules, and applications.

| Variable | Description                                                  |
| -------- | ------------------------------------------------------------ |
| NEON_DB  | Connection string to Neon database. If using other database, set to connection string of your own PostgreSQL database. |
